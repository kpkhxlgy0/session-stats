# Session Stats v0.4.2

修复原生子代理会话统计全部显示 `—`，并减少高延迟 RC 连接上的刷新请求等待。

- 识别子代理日志的根会话 ID 与直接父线程 ID，支持真实的一层和嵌套子代理。当前线程与日志身份仍严格校验；这些字段不会隐式继承父会话指标。
- 每阶段的三个远程目录检查改为并发。保留全部九次 RPC、前后两阶段检查、目标文件校验、取消处理和五秒总期限，串行等待从九轮减少为五轮。
- 快照格式、TPS 口径、权限和依赖不变，最低 Codex++ 版本仍为 1.0.6。

验证：350 项测试通过。真实本机一层和嵌套子代理均恢复可用统计；真实远程会话的接收值与同一发布快照的全部指标一致。一次新建接收器读取已有远程快照用时约 1.8 秒，两个刷新请求约 2.1–2.2 秒。700 ms 往返延迟模拟中，刷新请求从原先五秒内无法完成变为约 3.56 秒完成。上述实测是特定连接与样本，不代表所有机器的界面耗时。

开发链接因 Git 元数据变化而触发无关重载的问题由 **Codex++ v1.0.7** 单独修复。升级核心后需完整退出并重启 Codex；该主进程改动不能通过 tweak 热重载加载。
