# Session Stats v0.5.0

在 Subagents 中打开某个子代理详情时，面板底部会居中显示该子代理自己的 turns、steps、TPS、累计 Token 和缓存命中率。

- 统计距面板底边 2px，以零高度绝对定位悬浮显示，不占布局空间，不给正文或输入框增加留白。
- 切换子代理或主机时同步更换统计；旧请求不会覆盖新选择。返回列表、隐藏或关闭面板时移除统计。
- 可交互子代理只显示一份面板统计，不在其输入框下重复显示。
- 沿用现有本地日志和 Remote Control 快照，保持统计公式、去重规则和主会话底栏行为；缺少有效 TPS 样本时显示 `—`，不显示上下文占用。
- 仅修改 tweak，无需升级 Codex++ 核心；最低运行时版本仍为 1.0.6。

验证：367 项测试通过，tweak 校验通过，独立代码审查无实质问题。本地日志确认了子代理身份绑定和统计读取，以及开发链接热加载。底部悬浮布局通过静态界面结构和 DOM/CSS 测试验证，未进行自动化截图验收。
