# Session Stats v0.6.0 — 按需统计

仅为当前打开的会话和选中的子代理计算统计。切换、隐藏或关闭视图后撤销对应需求；没有可见目标时，不再扫描最近会话或持续计算历史会话。

- 多窗口分别持有统计需求，关闭一个窗口不会影响其他窗口。
- 远程通过短租约请求统计，切走发送撤销请求，断线后需求自动过期；慢 RPC 等待期间仍会为可见目标续租。
- 已发出的读操作可能完成，但撤销后的结果不会重新发布，也不会继续轮询。
- 跨多轮平均 TPS、fork 继承历史及其他统计公式保持不变。

完整远程按需行为要求运行端和接收端均升级到 **0.6.0**。旧 v1 快照仍可读取；无需升级 Codex++ 核心。

验证：393 项自动化测试、tweak 校验通过。真实本地会话和子代理已验证切换及停止读取；真实远程会话验证了两端统计一致、持续续租和撤销后停止更新。没有可用的真实远程子代理样本，此项由本地真实子代理及远程协议自动测试覆盖。
